# Search — NLP Learning Series

This folder contains notebooks related to search systems in Natural Language Processing (NLP).

The notebooks demonstrate how both traditional and modern search techniques work, starting from keyword-based retrieval to semantic search using sentence embeddings.

## Topics Covered

- Semantic search using sentence embeddings
- Top-K document retrieval
- Query–document matching
- TF-IDF based search vs semantic search
- Simple FAQ search system

## Notebooks Included

- `semantic_search_top_k.ipynb` — Retrieve top-K relevant documents using semantic similarity
- `query_document_matching.ipynb` — Match a user query with the most relevant document
- `tfidf_search_vs_semantic_search.ipynb` — Compare keyword-based search with semantic search
- `simple_faq_search.ipynb` — Build a basic FAQ search system using embeddings

## Purpose

Search systems are a core component of modern NLP applications such as chatbots, recommendation engines, and question answering systems.
This folder demonstrates how semantic representations improve retrieval quality compared to traditional methods.
