# Vector Database RAG with FAISS

This project demonstrates a Retrieval-Augmented Generation pipeline using FAISS for fast similarity search over document embeddings.

## Overview

Documents are converted into embeddings and indexed using FAISS. User queries are embedded and searched against the index to retrieve relevant context before generating answers.

## Objective

To illustrate how vector databases enable scalable and efficient retrieval in modern RAG systems.

## Key Concepts

* Vector Databases
* FAISS Indexing
* Semantic Search
* Retrieval-Augmented Generation

## Libraries Used

* sentence-transformers
* transformers
* faiss-cpu
* sentencepiece
* torch

## Outcome

Shows how FAISS enables efficient similarity search and forms the backbone of large-scale AI retrieval systems.
