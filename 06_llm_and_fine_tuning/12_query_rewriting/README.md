# Query Rewriting for Improved Retrieval

This project demonstrates how Large Language Models can reformulate unclear or incomplete user queries into well-structured questions before retrieval.

## Overview

User queries are rewritten to improve clarity and completeness, which can significantly enhance retrieval performance in RAG systems.

## Objective

To show how query rewriting improves search quality and robustness in conversational AI systems.

## Key Concepts

* Query Reformulation
* Prompt Engineering
* Conversational Search
* RAG Optimization

## Libraries Used

* transformers
* sentencepiece
* torch

## Outcome

Demonstrates that rewriting vague queries into clear questions can improve downstream retrieval and answer generation.
