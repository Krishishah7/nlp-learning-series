# Hybrid Retrieval in RAG

This project demonstrates a hybrid retrieval approach combining keyword-based TF-IDF search with semantic embedding-based search.

## Overview

Both keyword and semantic similarity scores are computed and combined to improve retrieval accuracy.

## Objective

To show how hybrid retrieval improves performance by leveraging both exact word matching and semantic understanding.

## Key Concepts

* Hybrid Search
* TF-IDF
* Semantic Embeddings
* Retrieval-Augmented Generation

## Libraries Used

* sentence-transformers
* transformers
* scikit-learn
* numpy
* sentencepiece

## Outcome

Demonstrates that combining keyword and semantic signals leads to more robust and accurate retrieval results.
