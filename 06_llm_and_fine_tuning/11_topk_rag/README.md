# Top-K Retrieval-Augmented Generation

This project demonstrates a multi-document RAG pipeline that retrieves the Top-K most relevant documents before generating an answer.

## Overview

Instead of relying on a single document, multiple relevant pieces of information are combined to provide richer context for the language model.

## Objective

To show how multi-document retrieval improves answer completeness and accuracy in RAG systems.

## Key Concepts

* Top-K Retrieval
* Multi-Document Context
* Vector Search with FAISS
* Retrieval-Augmented Generation

## Libraries Used

* sentence-transformers
* transformers
* faiss-cpu
* sentencepiece
* torch

## Outcome

Demonstrates that combining multiple relevant documents leads to more informative and reliable responses.
