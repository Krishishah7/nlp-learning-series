# LLM-Based Query Classification

## Overview
This project implements an LLM-based query classification system that categorizes user queries into predefined domains using prompt engineering.

## Features
- Intent detection using LLM
- Category classification (Education, Math, Knowledge)
- Prompt-based decision making
- Simple and extensible pipeline

## How It Works
User Query → Prompt → LLM → Category Output

## Tech Stack
- Python
- Transformers
