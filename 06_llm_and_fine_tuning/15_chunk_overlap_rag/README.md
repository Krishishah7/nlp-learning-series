# Chunk Overlap in RAG

This project demonstrates how overlapping chunks improve retrieval quality in Retrieval-Augmented Generation systems.

## Overview

Instead of splitting documents into independent chunks, overlapping segments are created to preserve contextual continuity across boundaries.

## Objective

To reduce information loss during chunking and improve retrieval accuracy in RAG pipelines.

## Key Concepts

* Chunk Overlap
* Context Preservation
* Document Segmentation
* Retrieval-Augmented Generation

## Libraries Used

* sentence-transformers
* transformers
* faiss-cpu
* numpy

## Outcome

Demonstrates that overlapping chunks improve retrieval by retaining important contextual information across chunk boundaries.
