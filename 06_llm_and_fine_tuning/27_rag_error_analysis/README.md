# RAG Error Analysis and Failure Debugging

## Overview
This project focuses on analyzing failure cases in Retrieval-Augmented Generation (RAG) systems by identifying incorrect predictions and categorizing errors.

## What This Project Does
- Runs RAG system on evaluation queries
- Compares predictions with ground truth
- Identifies incorrect predictions
- Categorizes errors into types
- Provides insights into failure patterns

## Why This Matters
Evaluation metrics alone are not sufficient. Understanding why a system fails is critical for improving performance.

## Features
- Error classification (false positives, false negatives)
- Failure case logging
- Insight generation

## Tech Stack
- pandas
- numpy
- sentence-transformers
