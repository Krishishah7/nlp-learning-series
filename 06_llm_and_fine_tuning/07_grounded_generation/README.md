# Grounded Generation Using Context

This project demonstrates how providing factual context can reduce hallucination in Large Language Models.

## Overview

The model is asked a factual question both with and without supporting context. The grounded version produces more accurate responses.

## Objective

To illustrate how context injection improves factual reliability and forms the basis of Retrieval-Augmented Generation (RAG).

## Key Concepts

* Grounded Generation
* Context Injection
* Hallucination Reduction
* RAG Fundamentals

## Libraries Used

* transformers
* sentencepiece
* torch

## Outcome

Shows that supplying relevant context enables the model to produce correct answers even when it otherwise hallucinated.
