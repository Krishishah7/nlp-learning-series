# Explainable AI Agent

## 📌 Overview
This notebook implements an explainable AI agent that processes user queries by identifying intent, selecting appropriate actions, and generating step-by-step reasoning.

## 🚀 Features
- Intent classification (calculation, knowledge, explanation)  
- Reason generation for decisions  
- Tool-based execution  
- Step-by-step reasoning  
- Confidence scoring  

## 🎯 Goal
To build a transparent AI system that provides both answers and the reasoning behind them.
