# Mini Retrieval-Augmented Generation (RAG)

This project implements a simple Retrieval-Augmented Generation pipeline using keyword-based document retrieval.

## Overview

Relevant information is retrieved from a small knowledge base and provided to the language model as context before generating an answer.

## Objective

To demonstrate the core idea behind RAG systems: combining information retrieval with language generation to reduce hallucinations.

## Key Concepts

* Retrieval-Augmented Generation (RAG)
* Context Grounding
* Keyword-Based Retrieval
* Hallucination Reduction

## Libraries Used

* transformers
* sentencepiece
* torch

## Outcome

Shows that retrieving relevant context enables more accurate and reliable answers compared to using the model alone.
