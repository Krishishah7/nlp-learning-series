# Production-Level RAG System

## Overview
This project integrates multiple advanced RAG techniques into a single production-level system, including multi-hop reasoning, conversational memory, tool usage, confidence scoring, and feedback learning.

## Features
- Multi-hop retrieval
- Conversational memory
- Tool-augmented reasoning
- Confidence scoring
- Feedback-based learning

## System Flow
Query → Memory → Tools → Retrieval → Answer → Confidence → Feedback

## Tech Stack
- sentence-transformers
- numpy
- pandas
