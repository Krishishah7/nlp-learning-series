# Prompt Engineering Basics

This project demonstrates how prompt design influences the behavior and output quality of Large Language Models (LLMs).

## Overview

Three prompt styles are compared:

* Vague prompt with minimal instruction
* Structured prompt with clear constraints
* Role-based prompt assigning a specific persona

## Objective

To understand how clarity, context, and instructions improve LLM responses without modifying the model itself.

## Key Concepts

* Prompt Engineering
* Instruction Following
* Role Prompting
* Output Control

## Libraries Used

* transformers
* torch
* accelerate
* sentencepiece

## Outcome

Shows that well-designed prompts produce more accurate, relevant, and user-specific responses from LLMs.
