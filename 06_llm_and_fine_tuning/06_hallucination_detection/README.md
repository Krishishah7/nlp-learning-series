# Hallucination Detection in LLMs

This project demonstrates how Large Language Models can produce confident but incorrect factual information, known as hallucinations.

## Overview

Factual questions are asked to the model, and responses are compared against known correct answers to identify inaccuracies.

## Objective

To highlight the reliability challenges of LLMs and demonstrate simple techniques for detecting incorrect outputs.

## Key Concepts

* LLM Hallucination
* Factual Accuracy
* Reliability Evaluation
* Model Safety

## Libraries Used

* transformers
* sentencepiece
* torch

## Outcome

Shows that even instruction-tuned models may generate incorrect facts, emphasizing the need for validation in real-world applications.
