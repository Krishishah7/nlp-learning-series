# RAG Evaluation

This project demonstrates how to evaluate the performance of a Retrieval-Augmented Generation system using semantic similarity.

## Overview

Model-generated answers are compared with ground truth answers using embedding-based cosine similarity.

## Objective

To measure the accuracy and quality of responses produced by a RAG system.

## Key Concepts

* Model Evaluation
* Semantic Similarity
* Cosine Similarity
* RAG Validation

## Libraries Used

* sentence-transformers
* scikit-learn

## Outcome

Provides a quantitative measure of how well the RAG system performs across different queries.
