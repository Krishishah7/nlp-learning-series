# Semantic Feedback Memory Agent

## 📌 Overview
This notebook implements an AI agent that improves responses by retrieving past user feedback using semantic similarity instead of exact query matching.

## 🚀 Features
- Intent classification  
- Feedback memory storage  
- Semantic similarity search  
- Reuse of past corrections  
- Improved response generalization  

## 🎯 Goal
To build an AI system that can generalize learning from past feedback to similar queries.
