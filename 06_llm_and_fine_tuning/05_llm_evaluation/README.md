# LLM Response Evaluation

This project demonstrates techniques for evaluating the quality and consistency of responses generated by Large Language Models.

## Overview

Multiple responses are generated for the same prompt using stochastic sampling. These responses are compared using cosine similarity to assess consistency and variability.

## Objective

To quantify how stable or diverse model outputs are when answering identical queries.

## Key Concepts

* LLM Evaluation
* Response Consistency
* Text Similarity
* Cosine Similarity
* Output Variability

## Libraries Used

* transformers
* scikit-learn
* numpy
* sentencepiece

## Outcome

Provides a quantitative measure of how similar or different responses are, helping assess reliability of model outputs.
