# Query Action System

## Overview
This project implements a decision-based system that routes user queries to appropriate actions such as calculation, explanation, or knowledge retrieval.

Unlike tool-augmented RAG systems, this project focuses on deciding the correct action before execution, rather than retrieving information first.

## Features
- Query classification using rules
- Action-based routing
- Tool execution (calculator, explanation, knowledge)
- Deterministic and stable outputs

## How It Works
User Query → Decision → Action → Response
