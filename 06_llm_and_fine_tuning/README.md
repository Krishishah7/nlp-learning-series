# LLM and Fine-Tuning Series

This section of the NLP Learning Series focuses on modern Large Language Model (LLM) techniques and transformer fine-tuning approaches used in real-world AI systems.

It covers prompt engineering, zero-shot and few-shot learning, reasoning techniques, evaluation methods, and model fine-tuning strategies to adapt pretrained models to specific tasks.

## Topics Covered

* Zero-shot and Few-shot Learning
* Prompt Engineering Techniques
* Chain-of-Thought Prompting
* LLM Evaluation Methods
* Transformer Fine-Tuning
* Parameter-Efficient Fine-Tuning (PEFT / LoRA)
* Instruction Tuning
* Practical LLM Applications

## Goal

The goal of this series is to build a strong foundation in applied LLM engineering — from using pretrained models effectively to customizing them for domain-specific tasks.

Each subfolder contains an individual project notebook demonstrating a specific concept.
