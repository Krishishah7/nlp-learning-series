# Query Normalization in RAG

This project demonstrates how normalizing user queries improves consistency and retrieval accuracy in a RAG system.

## Overview

Different variations of the same query can lead to inconsistent results. This notebook standardizes queries before processing.

## Objective

To improve robustness of RAG systems by handling diverse user input formats.

## Key Concepts

* Query Normalization
* Text Cleaning
* Input Standardization
* Retrieval Stability

## Libraries Used

* re (Python standard library)

## Outcome

Ensures consistent system behavior across different query variations, improving reliability and user experience.
