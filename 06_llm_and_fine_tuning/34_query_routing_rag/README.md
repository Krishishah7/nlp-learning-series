# Query Classification and Routing in RAG

## Overview
This project implements a multi-domain RAG system that classifies user queries and routes them to the appropriate domain-specific retrieval pipeline.

## Features
- Query classification based on intent
- Domain-specific document retrieval
- Intelligent routing
- Fallback for unknown queries

## How It Works
Query → Classifier → Route → Domain RAG → Answer

## Tech Stack
- Python
- NumPy
- Pandas
