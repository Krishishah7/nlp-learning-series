# RAG Caching

This project demonstrates how caching can improve the efficiency of a Retrieval-Augmented Generation (RAG) system.

## Overview

Repeated queries in RAG systems can lead to redundant computation. This notebook introduces a caching mechanism to store and reuse previous results.

## Objective

To optimize performance by reducing unnecessary recomputation for repeated queries.

## Key Concepts

* Caching
* Performance Optimization
* Query Reuse
* System Efficiency

## Libraries Used

* sentence-transformers
* transformers
* scikit-learn
* time (Python standard library)

## Outcome

Demonstrates that caching significantly reduces response time for repeated queries and improves system efficiency.
