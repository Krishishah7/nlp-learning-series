# Document Chunking in RAG

This project demonstrates how document chunking improves retrieval quality in Retrieval-Augmented Generation systems.

## Overview

Large documents are split into smaller chunks before embedding and retrieval. This allows the system to retrieve more precise and relevant context for answering queries.

## Objective

To show how chunking enhances retrieval accuracy and prevents loss of relevant information in large text inputs.

## Key Concepts

* Document Chunking
* Context Segmentation
* Vector Search with FAISS
* Retrieval-Augmented Generation

## Libraries Used

* sentence-transformers
* transformers
* faiss-cpu
* numpy

## Outcome

Demonstrates that splitting documents into smaller chunks leads to more accurate retrieval and better answer generation.
