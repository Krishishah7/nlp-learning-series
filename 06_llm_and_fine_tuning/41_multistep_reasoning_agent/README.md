# Multi-Step Reasoning Agent

## Overview
This project implements a multi-step reasoning agent that decomposes complex user queries into smaller tasks, executes them sequentially, and combines the results into a final response.

## Features
- Task decomposition
- Step-by-step execution
- Tool chaining
- Controlled output generation

## How It Works
User Query → Step Detection → Execution → Result Combination
