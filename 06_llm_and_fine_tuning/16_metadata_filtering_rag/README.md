# Metadata Filtering in RAG

This project demonstrates how metadata filtering improves retrieval quality in Retrieval-Augmented Generation systems.

## Overview

Documents are filtered based on metadata (such as category) before performing similarity search. This reduces noise and improves retrieval precision.

## Objective

To show how pre-filtering documents enhances relevance and efficiency in RAG pipelines.

## Key Concepts

* Metadata Filtering
* Context Selection
* Retrieval Optimization
* Retrieval-Augmented Generation

## Libraries Used

* sentence-transformers
* transformers
* faiss-cpu
* numpy

## Outcome

Demonstrates that filtering documents before retrieval leads to more relevant results and improved answer quality.
