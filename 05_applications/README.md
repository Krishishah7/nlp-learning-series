# Applications — NLP Learning Series

This folder contains real-world NLP applications built by combining embeddings, similarity techniques, and transformer-based models into complete systems.

The focus of this section is on moving beyond individual NLP techniques and designing end-to-end, practical applications that resemble real industry use cases.

## What This Section Demonstrates

- Applying sentence embeddings to solve real problems
- Designing multi-step NLP pipelines
- Combining semantic similarity with rule-based logic
- Adding explainability to NLP systems
- Building modern retrieval-based architectures

## Applications Included

- **Resume–Job Matcher**  
  Semantic matching between a resume and a job description using sentence embeddings.

- **Multi-Resume Job Ranker**  
  Ranking multiple resumes against a single job description based on semantic similarity.

- **Skill-Based Weighted Resume Scoring**  
  Enhancing resume matching by combining semantic similarity with explicit skill extraction and weighted scoring.

- **Resume Matching Score Analysis & Explainability**  
  Breaking down semantic and skill-based scores to explain why a resume was ranked higher or lower.

- **Mini Semantic Document Search Application**  
  Retrieving the most relevant documents for a user query using semantic search.

- **Mini Retrieval-Augmented Generation (RAG) Pipeline**  
  Demonstrating a complete RAG architecture by combining document retrieval with context-based answer generation.

## Purpose

The goal of this section is to bridge the gap between NLP concepts and real-world systems.  
These notebooks demonstrate how embeddings, similarity search, and retrieval can be combined to build practical applications such as recruitment tools, search engines, and knowledge assistants.

This folder represents the transition from learning individual techniques to designing complete NLP systems.
